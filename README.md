# buyback-russia

Обратный выкуп акций российскими компаниями: данные МСФО, расчёты и модели для диссертации.

Автор: Д. Е. Борисовский. Материалы к статье «Обратный выкуп акций в России: экономический портрет компании».

## Что здесь лежит

| Папка | Что внутри |
|---|---|
| `pre_cancellation/` | Панель «компания – год» из отчётности МСФО и капитализации (`panel.csv`), все извлечённые строки МСФО (`msfo_long.csv`), профиль компаний перед погашением акций (`pre_cancellation_results.xlsx`), сравнение капитальных затрат (`capex_comparison.xlsx`). |
| `buyback_precursors_1pct/` | Главный набор данных `dataset.csv`: признаки компании на конец года t−1 и факт выкупа в году t. Выкупом считается год, когда на выкуп потрачено не меньше 1% капитализации. Результаты: `precursors_results.xlsx` (что предшествует выкупу), `score_significance.xlsx` (проверка балла с учётом того, что годы одной компании связаны), `cancel_precursors.xlsx` (что предшествует погашению). |
| `pbv_hypothesis_1pct/` | Проверка гипотезы «выкупают дешёвые акции» по P/BV: `pbv_hypothesis_results.xlsx` и справочная таблица `PBV_выкупавших_компаний.xlsx` (по компаниям и по годам выкупа). |
| `management_motives/` | Заявленные менеджментом мотивы выкупа и погашения. |
| `colab.ipynb` | Блокнот для Google Colab: ставит зависимости и пересчитывает все результаты из `dataset.csv`. |

Каждый `summary.json` хранит итоговые цифры, которые вошли в статью.

## Основные цифры (порог выкупа 1% капитализации)

- 450 компаний-лет, из них 63 года с выкупом; выкупали 34 компании.
- Если у компании не выполнено ни одного из пяти условий, выкуп случался в 2% лет, если выполнено 4–5 условий, то в 24% лет.
- Медианный P/BV выкупавших компаний 1,81, остальных 0,97. Гипотеза о том, что выкупают в основном дешёвые акции, не подтверждается.

## Как пересчитать результаты

В Google Colab: откройте `colab.ipynb` и выполните ячейки по порядку.

На своём компьютере (Python 3.10+):

```bash
pip install -r requirements.txt
cd buyback_precursors_1pct
python3 analyze.py             # precursors_results.xlsx, summary.json
python3 score_significance.py  # score_significance.xlsx
python3 cancel_precursors.py   # cancel_precursors.xlsx, cancel_summary.json
cd ..
python3 pbv_hypothesis_1pct/pbv_hypothesis.py
```

Результаты пересчитываются из `dataset.csv` и `pre_cancellation/panel.csv` и совпадают с опубликованными.

## Чего здесь нет и почему

- **Дневные котировки и обороты Мосбиржи.** Их распространение регулируется правилами биржи, поэтому они не выложены. Скрипт `buyback_precursors_1pct/fetch_market.py` скачивает их заново через открытый ISS API Мосбиржи в папку `market_cache/`. Из публикуемых таблиц убраны также цены закрытия на конец года (столбцы `price`, `close`, `value`). Капитализация и производные показатели (P/BV, доходности, просадки) оставлены.
- **Исходные файлы отчётности МСФО** (`.xlsx` по компаниям) и сводный файл `Анализ_акций_Мосбиржи.xlsx`. Все числа, извлечённые из отчётности, есть в `pre_cancellation/msfo_long.csv` и `buyback_precursors_1pct/msfo_extra.csv`, с названием исходной строки для проверки.

Чтобы пересобрать данные с нуля, положите файлы МСФО в папку `raw_msfo/` в корне репозитория, файл `Анализ_акций_Мосбиржи.xlsx` в `pre_cancellation/`, индекс IMOEX в `buyback_cancellation/price_cache/IMOEX.csv`, и запустите по порядку: `pre_cancellation/extract_msfo.py`, `pre_cancellation/build_panel.py`, `buyback_precursors_1pct/fetch_market.py`, `buyback_precursors_1pct/extract_extra.py`, `buyback_precursors_1pct/build_dataset.py`.

## Словарь основных столбцов `dataset.csv`

- `company`, `year` — тикер и год t.
- `bb_1` — выкуп в году t не меньше 1% капитализации (используется как `bb`); `bb_05` и `bb_any` — более мягкие пороги.
- `cancel` — погашение акций в году t (число акций на конец года меньше, чем годом раньше).
- `f_*` — признаки на конец года t−1: рентабельность (`f_roe`, `f_roa`), денежная позиция (`f_cash_assets`, `f_net_cash`), долг (`f_debt_assets`, `f_nd_ebitda`), дивиденды (`f_div_yield`, `f_payout`), оценка (`f_pbv`, `f_ep`, `f_ev_ebitda`), динамика цены относительно IMOEX, выкуп в прошлом году (`f_bb_prev`).
- `c_*` — показатели в самом году t (для описания, а не для прогноза).
- `state`, `foreign`, `bank`, `sector` — госучастие, иностранный контроль, банк, отрасль.
